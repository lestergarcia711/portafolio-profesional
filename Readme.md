# 🚀 Portafolio – Lester García

Portafolio web personal desarrollado con **HTML, CSS puro y JavaScript** (sin librerías).

## ✨ Secciones
- **Inicio**: foto principal, presentación y botones de acción (incluye descarga de CV)
- **Sobre mí**
- **Habilidades** (6)
- **Proyectos** (5, con imagen y enlace)
- **Trayectoria**
- **Contacto**: WhatsApp, correo, LinkedIn y GitHub + formulario
- **Sidebar** fija con navegación (menú desplegable en móvil)

## 🎨 Paleta
Verde neón `#39ff14` · Azul suave `#7cc4ff` · Naranja suave `#ffb26b` · Fondo `#0b1020`

## 📁 Estructura
```
index.html
css/styles.css
js/main.js        ← CONFIG con tus datos de contacto
img/              ← perfil, proyectos y capturas
docs/             ← coloca aquí CV-Lester-Garcia.pdf
```

## ⚙️ Personalización
1. Abre `js/main.js` y edita el bloque `CONFIG` (WhatsApp, correo, LinkedIn).
2. En `index.html` cambia el `href` de cada proyecto por su enlace real.
3. Ajusta los niveles de habilidad con `data-level` y los textos de Trayectoria.
4. Reemplaza las imágenes de `img/` por capturas reales de tus proyectos.

## ▶️ Uso
Abre `index.html` en el navegador o usa Live Server en VS Code.
